# Coding Club – web stranica školskog IT kluba

Projektni zadatak iz predmeta Softversko inženjerstvo (4. razred gimnazije, IT smjer), školska 2026/2027.

**Autor:** Haris Džananović (samostalni rad)

**Repozitorij:** https://github.com/harisdzananovicsa-cloud/coding-club-stranica

## O projektu

Prezentacijska web stranica školskog kluba za programiranje i tehnologiju. Stranica predstavlja klub, članove i projekte te ima formu za prijavu novih članova.

## Sekcije stranice

- **Početna** – hero sekcija s kratkim opisom kluba i dugmetom za prijavu
- **O nama** – opis kluba i članovi
- **Projekti** – kartice s projektima koje klub radi
- **Prijavi se** – forma za prijavu s JavaScript validacijom
- Responzivan dizajn (mobitel i računalo), meni s hamburger dugmetom na mobitelu

## Tehnologije

HTML5, CSS3, JavaScript (bez vanjskih biblioteka). Fontovi se učitavaju s Google Fonts.
